NLP Pipeline

Pipeline thật trong code: parse → normalize → chunk → match → explain

01

Ingestion & Parsing

  • PDF: PyMuPDF đọc text layer.
  • DOCX: python-docx đọc XML UTF-8.
  • File lưu S3-compatible storage.
02

Normalize & Evidence

  • Underthesea tokenize tiếng Việt, lọc stopword.
  • SectionDetector Việt/Anh + confidence.
  • Chunk line / sentence / window, giữ char offsets.
03

Semantic Matching

  • MiniLM multilingual lazy-load singleton.
  • Batch encode; vector chuẩn hóa.
  • Cosine = dot product; threshold 0.30.

Scoring

Must-have ×2, nice-to-have ×1; cộng kinh nghiệm và học vấn theo trọng số JD.

Agent reasoning

Extractor → Evaluator → Question Generator → Verifier, có vòng self-reflection.

Output

Điểm 0–100, matched/missing skills, strengths, concerns, evidence và câu hỏi.

Lưu ý tích hợp: pipeline CVFingerprint/cache trong src/cache/pipeline.py được xây riêng; luồng upload/scoring nghiệp vụ hiện dùng raw_text và ResumeScorer.
Scoring Logic

Điểm số có công thức — và có đường lui an toàn

Total= Skill × 0.60 + Exp × 0.30 + Edu × 0.10

KW

Nếu model embedding không load được, hệ thống ghi lỗi và tiếp tục bằng keyword-only.

Skills · 60%

Exact/alias + Underthesea; phần miss được so sánh semantic theo chunk. Must-have nặng gấp đôi.

Experience · 30%

Regex Việt/Anh, lấy số năm hợp lệ cao nhất, chặn false positive >50 năm.

Education · 10%

Rank high school → bachelor → master → PhD; thấp hơn 1 bậc nhận 50 điểm.

Per-job weights

JD cho phép cấu hình 3 trọng số; service tự normalize tổng về 1.0.

Explainability by design: match_details lưu method, similarity, matched/missing, weights và từng score con trong PostgreSQL JSONB.

Performance Engineering

Các lớp tối ưu phối hợp để giảm chi phí xử lý

AI

Lazy singleton

Underthesea và MiniLM chỉ load ở lần dùng đầu; khóa thread tránh load trùng trong process.

Σ

Batch vectors

Encode skills/chunks theo batch; normalize rồi dot-product toàn ma trận.

Q

Worker control

Celery concurrency 4, prefetch 1, ack-late, soft/hard limit 300/360s.

↺

Resilient cache

Redis timeout 0.5s, circuit breaker, memory fallback và distributed single-flight.

Tái sử dụng kết quả

  • Parse cache và duration cache tách version/key.
  • Keyword-first tránh gọi embedding khi đã match đủ.
  • Async SQLAlchemy và FastAPI cho I/O.

Kiểm soát tác vụ nền

  • Celery tách tác vụ nặng khỏi luồng request.
  • Prefetch 1 và ack-late kiểm soát phân phối công việc.
  • Circuit breaker duy trì luồng xử lý khi Redis lỗi.
Security & Privacy

Kiểm soát truy cập xuyên suốt API và lưu trữ

Identity & Access

  • JWT HS256: access 30′, refresh 7 ngày.
  • HttpOnly + SameSite=Lax cookie.
  • RBAC: candidate / recruiter / leader / admin.
  • Bcrypt password hashing.

API & Storage

  • CORS origin/method/header explicit.
  • SlowAPI rate limiting cho auth.
  • Presigned object URL; storage TLS flag.
  • Startup chặn secret yếu ở production.

Authorization Scope

  • Dependency guards xác thực user trên endpoint được bảo vệ.
  • Role guards giới hạn nghiệp vụ candidate, recruiter, leader và admin.
  • Dữ liệu báo cáo được lọc theo doanh nghiệp của recruiter.
  • Object storage dùng presigned URL thay vì public URL cố định.
